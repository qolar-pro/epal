# Aster – Greek B2B store for Google review cards (v4)

Multi-page static store (generated by `scripts/build.js`) + two serverless functions (`api/order.js`, `api/contact.js`). No dependencies, no framework.

- **Store:** home, catalog, 3 product pages with live designer (card / stand / sticker) and QR link checker, quantity tiers, cart, checkout, order confirmation.
- **Greece-specific:** prices ex-VAT with a VAT toggle, 24% VAT, Greek phone/postcode validation, ΑΦΜ checksum validation, invoice-or-receipt choice, ACS/Speedex/ΕΛΤΑ Courier shipping with island rates, bank transfer/IRIS and cash on delivery, Greek legal pages.
- **B2B:** multi-store tool (one line per store → one cart line each), quantity discounts across stores, quote request form.
- **Server:** the API re-validates everything and recomputes the price (client totals are never trusted), escapes user text in emails, has a honeypot, and sends mail via Resend if configured. Strict CSP and security headers in `vercel.json`.
- **Tests:** `node tests/run.js` (validators, pricing, API with mocked mail/Stripe). `node tests/serve.js` runs a local server with clean URLs and the same headers.

See **LAUNCH.md** for everything that must be done before this takes real orders.
Edit `config.js`, then `node scripts/build.js`.
